# AILearn｜AI 新手課前需求問卷

問卷網址：[https://ai.mzoo.cc/](https://ai.mzoo.cc/)

提供 AI 初學者參考選項與自由填寫，調查使用經驗、網頁用途、學習主題、工作與生活痛點、首要目標、學習顧慮與設備。共 14 題，分成四段，只有 AI 經驗、學習主題、最優先需求三題必填。匿名填答，回覆寫入老師的私人 Google 試算表。

## 本機預覽

執行 `python -m http.server 8765`，開啟 `http://localhost:8765/`。無需安裝前端套件或建置。

## 檔案

- `index.html`：頁面與表單外框。
- `styles.css`：桌機、平板與手機樣式。
- `app.js`：題目、選項、草稿恢復、驗證與送出。
- `config.js`：Google Apps Script 的公開收件網址，不含金鑰。
- `backend/Code.gs`：Google Apps Script 後端原始碼。

## 資料與維護

試算表維持私人，請勿將回覆或試算表匯出檔加入公開 Repo。頁面只接收回覆，不讀取試算表。資料寫入後才顯示成功，網路錯誤可用同一回覆編號重送，避免重複資料。文字寫入前處理試算表公式開頭，避免自由填答被當成公式執行。

草稿僅儲存在填答者自己的瀏覽器，成功送出後清除；可透過頁面上的清除草稿功能移除。共用裝置請在填答後清除草稿。

若後續更改後端，須在 Apps Script 管理部署更新版本；收件網址保持不變。`setup` 僅在首次執行建立試算表，重跑不會覆蓋已有回覆。

GitHub Pages 由 `main` 分支根目錄發布。公開端點供匿名填答使用，不是防機器人安全邊界；目前提供蜜罐、大小限制、欄位驗證與重送去重。若大規模公開推廣，需再加伺服器端防濫用機制。
