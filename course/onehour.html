Lovable｜生成與調整

00–25 分鐘

看見第一版、做一次修改，取得可獨立開啟的HTML。

  1. 開啟已登入的 Lovable

    前往 https://lovable.dev/，在首頁的需求輸入區貼上下方「活動頁生成提示詞」，選擇開始建置的按鈕（常見為 Build／送出）。等待第一版；1～2分鐘是體驗目標，實際時間依平台而定。

    活動頁生成提示詞

    選一段貼給Lovable就能開始，不必先學色碼或程式。第一版確認後，再用下方的獨立HTML匯出提示詞取得可發布檔案。

    最快體驗版

    請幫我做一頁「週末自然散步」活動網頁。示範日期是2026年12月12日上午9點到12點，地點是大安森林公園。放上活動介紹、時間地點和集合地圖，風格自然清爽，並標示這是虛構教學活動。

    資訊清楚版

    請做一頁「週末自然散步」活動介紹，讓朋友一眼看懂什麼時候、在哪裡、要帶什麼。示範活動是2026年12月12日上午9點到12點，在大安森林公園。請加上簡單行程、地圖與常見問題，並標示沒有真實招募。

    帶清單版

    幫我製作一頁虛構的「週末自然散步」活動網頁：2026年12月12日上午9點到12點，大安森林公園。除了時間、地圖和行程，再做一份可以勾選的水壺、鞋子、防曬及雨具清單。畫面請用舒服的森林感。

    手機友善版

    請做一頁手機也好讀的「週末自然散步」活動網頁。示範日期2026年12月12日，上午9點到12點，地點大安森林公園。字要清楚，集合地圖按鈕要容易點，包含活動介紹、行程和準備事項，並標示為虛構教學示範。

    原完整版：包含完整規格

    請製作一個繁體中文（台灣用語）的一頁式活動網頁，主題為「週末自然散步」。這是虛構教學活動，請清楚標示「教學示範，沒有真實招募」。

活動資料：
- 示範日期：2026/12/12，09:00–12:00。
- 地點：臺北市大安森林公園；這是公開景點的示範，不代表真實集合安排。
- 對象：想在週末輕鬆散步的朋友。
- 行程：09:00集合暖身、09:30自然觀察、11:00休息分享、12:00結束。
- 準備清單：飲用水、好走的鞋子、帽子與防曬、雨具。
- FAQ：下雨怎麼辦、需要裝備嗎、這個頁面會收集個資嗎。
- 主要按鈕：「查看集合地圖」，連到 https://www.google.com/maps/search/?api=1&query=大安森林公園 ，另開分頁並加上 rel="noopener"。

版面與功能：
- 使用森林綠 #193f32、霧白 #f1f3ec、淺葉綠 #d9e9a4。
- 手機、平板、桌機依可用寬度重排，字體清楚、沒有橫向溢出。
- 有頁內導覽、活動資訊、行程、可勾選的準備清單與FAQ。
- 清單可勾選並顯示完成數量，使用此瀏覽器的本機儲存保留勾選；按鈕與連結都要能操作，保留鍵盤焦點。
- 不加入登入、資料庫、付款、報名表、平台內建AI、API或金鑰。

先產生可預覽第一版。完成後請另外建立一份 public/workshop/index.html：完整的獨立靜態網頁，CSS與JavaScript全部內嵌，不依賴框架、外部套件、伺服器或Lovable執行環境。讓我下載或從同步至GitHub的檔案中取得後，雙擊就能使用，再交給GitHub Pages發布。請不要把原專案的框架入口檔冒充獨立HTML。若尚未建立此檔，明確告訴我，並提供完整HTML原始碼。
  2. 檢查第一版

    在預覽中找到活動名稱、日期、地點及行程。點一次地圖、勾一個清單項目，切換窄版預覽確認手機文字和按鈕。

  3. 送出一次明確修改

    貼上「單次修改提示詞」，只改標題和手機按鈕。確認修改真的出現在預覽。

    單次修改提示詞

    請只修改活動標題為「週末森林小旅行」，並讓手機上的主要按鈕占滿可用寬度。保留行程、地圖、清單與FAQ。修改預覽後，也同步更新獨立的 public/workshop/index.html；不要只修改框架頁面。請列出你改了哪兩項，讓我驗收。
  4. 取得獨立靜態檔

    確認專案內確實有 public/workshop/index.html。若尚未建立，貼上「獨立HTML匯出提示詞」。原專案同步GitHub後可在該檔案頁點 Raw，或在Lovable的Code開啟檔案後選Copy file content，複製全部內容，用純文字編輯器另存 index.html（UTF-8，避免變成 index.html.txt）；若工具直接提供完整HTML，亦可照此存檔。不要只複製原框架的入口HTML。

    獨立HTML匯出提示詞

    請根據目前已確認的活動頁面，建立或更新完整的 public/workshop/index.html。這是一份獨立靜態HTML：CSS與JavaScript內嵌，不依賴伺服器、React、TanStack、Vite、外部套件或Lovable服務；雙擊可操作地圖、導覽、清單與FAQ。保留虛構活動標示與森林綠配色，請告知檔案路徑；若無法建立檔案，輸出完整HTML原始碼，不要只給修改片段。
  5. 雙擊驗收

    雙擊剛存的 index.html，在本機再次測試地圖、導覽及清單。離開Lovable仍可操作，才是本課可發布的靜態檔。

講師提問：Lovable預覽能動，就代表朋友已經能用正式網址看到嗎？

查看參考解答參考解答：還沒有。接著要保存程式碼、準備獨立靜態檔，再由Pages產生正式網址。

GitHub｜保存自己的程式碼

25–45 分鐘

保存Lovable原專案，再將獨立HTML放到公開的教學發布儲存庫。

  1. 連接並同步原專案

    在Lovable的聊天輸入區左下角按「＋」（Chat actions），選 Project → GitHub。使用既有帳號連線；若尚未連接，依介面選 Add connection／Add account，由學員本人完成登入與GitHub app授權。再於Accounts選 Connect，等待同步。此功能與GitHub API connector不同。

  2. 確認自己的程式碼已保存

    選 View on GitHub，看到原專案檔案及最新提交紀錄。Lovable新建的同步儲存庫預設私人；這份是原專案備份，不直接當Pages成品。找到 public/workshop/index.html，依上一段方式取得靜態檔；若不存在，回Lovable要求建立並等同步。

  3. 建立專用發布儲存庫

    在GitHub右上角「＋」選 New repository，名稱填 event-page，選 Public，加入README後建立。此課使用GitHub Free，因此發布儲存庫使用公開。僅放虛構活動HTML，不放私人資料或金鑰。保留Lovable來源儲存庫為私人；本課兩個儲存庫的用途不同。

  4. 新增 docs/index.html

    在 event-page 儲存庫選 Add file → Create new file。檔名輸入 docs/index.html（斜線會建立資料夾），貼上已本機驗收的完整HTML。選 Commit changes，填入「新增活動靜態頁」，提交至預設分支（本課以main示範）。

  5. 確認檔案與分支

    回到Code，確認main分支的docs資料夾內有index.html且內容完整。如果原專案的分支叫其他名稱，不影響本課新建event-page的main；Pages必須選實際放有docs檔案的分支。

講師提問：為什麼同步原始專案後，還另外放一份HTML到發布儲存庫？

查看參考解答參考解答：原專案可能需要框架或伺服器。Pages這條路線發布的是可獨立使用的靜態檔；分開保存也能避免把整份私人原專案公開。

GitHub Pages｜自動發布成網址

45–60 分鐘

設定一次發布來源，再用一次Commit驗證網站自動更新。

  1. 開啟 Pages 設定

    在event-page儲存庫選 Settings，在側邊選單的Code, planning, and automation區找到Pages；若看不到Settings，確認自己是儲存庫管理者。

  2. 選擇發布來源

    在Build and deployment的Source選 Deploy from a branch。Branch選main，Folder選/docs，按Save。若設定早已儲存且沒有變更，Save灰色是正常狀態，不必重設。這條路線不必另選GitHub Actions範本，也不要同時套用教材中的選用Actions設定。

  3. 等待並開啟正式網址

    到Actions查看Pages部署是否完成；回Settings → Pages找Visit site／網站網址。用該連結開啟，格式通常是 https://你的帳號.github.io/event-page/ 。等待時間不固定，不以此格式猜測部署已成功。

  4. 驗收並改一個字

    正式頁面確認標題、地圖與清單。回Code → docs/index.html，選編輯，把活動副標加上「歡迎一起散步」，Commit changes至main。等待部署成功，再重新整理正式網址，看到新文字即證明自動更新。

  5. 交出兩個網址

    交event-page儲存庫網址與Pages正式網址，附一張手機畫面和一句修改紀錄。若尚未發布成功，註明待補；404時先查部署狀態、main/docs和index.html大小寫，不要反覆建立新專案。

講師提問：我在Lovable改標題，這個Pages網址會立即跟著改嗎？

查看參考解答參考解答：本課Pages讀取event-page裡的靜態HTML。需要重新匯出、更新docs/index.html並提交，才會觸發自動發布；Lovable預覽的變動不會直接更新另一個發布儲存庫。
